📖 How to set up (2 minutes)

1

Create an app in the pCloud App Console and copy its App Key into PCLOUD_APP_KEY in the code — this is a one-time developer setup step.

2

Tap Connect pCloud above — a browser tab opens where you log in and approve access. No token to copy or paste.

3

Once it says Connected, tap Test Connection, then use Upload / Retrieve to sync.

Your access token is stored only on this device. Files are AES-256 encrypted before upload — pCloud only sees scrambled data.
