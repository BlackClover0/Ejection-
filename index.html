📖 How to set up (2 minutes)

1

Open Telegram → search @BotFather → send /newbot → give it any name → copy the Bot Token it gives you

2

Create a new private channel in Telegram → go to channel settings → Add your bot as Administrator with permission to post messages

3

Get your Chat ID: open web.telegram.org → click your channel → look at the URL. It will be like -100xxxxxxxxxx

4

Paste Bot Token + Chat ID above → tap Test Connection → then Save & Connect

Your bot token is stored only on this device. Files are AES-256 encrypted before upload — Telegram only sees scrambled data.
